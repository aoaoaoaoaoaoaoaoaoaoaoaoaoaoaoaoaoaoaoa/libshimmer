# libshimmer

Animated status lines for terminal UIs, paced by the host's work. A host makes a `Shimmer` from one of 17 stock recipes, tells it what the host is doing and how hard it works, and draws the status line it paints each frame, as plain data or, with the `ratatui` feature, as ratatui spans.

[design/DESIGN.md](design/DESIGN.md) holds the adopted design.
